# dotfiles

Personal configuration files for the Linux setup I use. I decided it would be wise to make my setup reproducible after bricking my setup one too many times.

## System requirements
Expected to be used with CachyOS and the Hyprland window manager. In particular:
- Configs currently synced for:
    - hypr
    - Noctalia
- Config files are expected to be stored in their respective folder inside `~/.config/`.

## How to use
1. Clone the repo: 
``` shell
git clone https://github.com/tiduseleven/dotfiles.git
```
2. Execute the script `dotfiles.sh` 
``` shell
cd dotfiles
chmod +x dotfiles.sh
./dotfiles.sh
```
